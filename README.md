# BilikMərkəzi — ilkin versiya

## Lokal açılış
`index.html` faylını brauzerdə açın.

## Pulsuz yayımlama
1. GitHub-da yeni public repository yaradın.
2. `index.html` faylını repository-yə yükləyin.
3. Settings → Pages → Deploy from a branch → `main` və `/root` seçin.
4. Yadda saxlayın. GitHub sayt üçün pulsuz `github.io` ünvanı yaradacaq.

Alternativ: Cloudflare Pages-də bu qovluğu yükləyərək statik sayt kimi yayımlayın.

## Hazırkı imkanlar
- Mobil uyğun dizayn
- 4 kateqoriya, hərəsində 5 sual
- Cavab seçimi və dərhal geribildirim
- Nəticə hesablanması
- Backend və ödəniş tələb etmir

## Növbəti mərhələ
Daha çox sual, admin paneli, nəticələrin saxlanması, SEO səhifələri və reklam inteqrasiyası.
